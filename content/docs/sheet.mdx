A panel that slides in from the edge of the screen, providing a focused space for forms, settings, or supplementary content without leaving the current page.

## Default

A sheet with an icon header: icon on the left, title and description stacked in a column, and an optional action on the right.

## Properties

### SheetHeader

Renders as a flex row: on the left, `SheetTitle` and `SheetDescription` in a column, and optional `SheetAction` on the right.

| Property    | Type     | Default | Description            |
| ----------- | -------- | ------- | ---------------------- |
| `className` | `string` | -       | Additional CSS classes |

| Child              | Description                                    |
| ------------------ | ---------------------------------------------- |
| `SheetTitle`       | Header title text                              |
| `SheetDescription` | Header description text                        |
| `SheetAction`      | Optional action rendered in the top-right toolbar next to the close button |

### SheetBody

Scrollable main content between `SheetHeader` and `SheetFooter`. Grows to fill the remaining sheet height (`flex-1 min-h-0`) so the header and footer stay visible while the body scrolls.

| Property    | Type     | Default | Description            |
| ----------- | -------- | ------- | ---------------------- |
| `className` | `string` | -       | Additional CSS classes |

### SheetAction

Optional header action (e.g. overflow menu). Place inside `SheetHeader`; it is hoisted into the absolute top-right toolbar (`flex` row with the close button).

| Property    | Type     | Default | Description            |
| ----------- | -------- | ------- | ---------------------- |
| `className` | `string` | -       | Additional CSS classes |
