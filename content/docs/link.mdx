title: Link
description: A styled link component built on top of Next.js Link. Supports multiple visual variants with icon start/end slots.
---

## Properties

| Property   | Type                                       | Default     | Description                              |
| ---------- | ------------------------------------------ | ----------- | ---------------------------------------- |
| variant    | `"primary"` \| `"secondary"` \| `"tertiary"` | `"primary"` | The variant style of the link            |
| iconStart  | `ReactNode`                                | -           | Icon displayed before the link text      |
| iconEnd    | `ReactNode`                                | -           | Icon displayed after the link text       |
| disabled   | boolean                                    | `false`     | Whether the link is disabled             |
| href       | string                                     | -           | The URL to navigate to                   |
| children   | ReactNode                                  | -           | The content of the link                  |
