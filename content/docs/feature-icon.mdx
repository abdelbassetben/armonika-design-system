## Properties

| Property | Type | Default | Description |
| -------- | ---- | ------- | ----------- |
| name     | `IconName` | — | The icon to display |
| variant  | `"default"` \| `"primary-light"` \| `"neutral"` \| `"secondary"` | `"default"` | The variant style |
| size     | `"xs"` \| `"sm"` \| `"md"` \| `"lg"` \| `"xl"` | `"md"` | The size of the icon container |
