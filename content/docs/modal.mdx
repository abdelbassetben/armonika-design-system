## Properties

| Property          | Type      | Default | Description                     |
| ----------------- | --------- | ------- | ------------------------------- |
| `showCloseButton` | `boolean` | `true`  | Show the default X close button |

### DialogContent

| Property          | Type        | Default | Description                     |
| ----------------- | ----------- | ------- | ------------------------------- |
| `showCloseButton` | `boolean`   | `true`  | Show the default X close button |
| `className`       | `string`    | -       | Additional CSS classes          |
| `children`        | `ReactNode` | -       | The content of the dialog       |

### DialogFooter

| Property          | Type                                   | Default | Description                           |
| ----------------- | -------------------------------------- | ------- | ------------------------------------- |
| `showCloseButton` | `boolean`                              | `false` | Show a default Close button           |
| `layout`          | `'end', 'start', 'stretch', 'stacked'` | `'end'` | Layout variant for the footer buttons |
| `className`       | `string`                               | -       | Additional CSS classes                |
| `children`        | `ReactNode`                            | -       | The content of the footer             |
