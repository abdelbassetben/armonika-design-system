## Properties

| Property    | Type                                                                  | Default     | Description                              |
| ----------- | --------------------------------------------------------------------- | ----------- | ---------------------------------------- |
| title       | `string`                                                              | -           | The title of the toast                   |
| description | `string`                                                              | -           | Optional description text                |
| variant     | `"default"` \| `"success"` \| `"error"` \| `"warning"` \| `"info"`   | `"default"` | The variant style of the toast           |
| action      | `{ label: string; onClick: () => void }`                              | -           | Optional action button                   |

## Custom Component

You can also use `toast.custom()` directly with your own component for full control:

<Tabs items={['Preview', 'Code']} defaultIndex={0}>

```tsx
import { toast as sonnerToast } from "sonner";

sonnerToast.custom((id) => (
  <div className="flex items-center gap-3 rounded-xl bg-white p-4 shadow-lg ring-1 ring-black/5 dark:bg-[#161615]">
    <p className="text-sm font-medium">Your custom content</p>
  </div>
));
```
