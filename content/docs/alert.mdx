## Properties

| Property  | Type                                                                             | Default     | Description                    |
| --------- | -------------------------------------------------------------------------------- | ----------- | ------------------------------ |
| variant   | `"default"` \| `"danger"` \| `"brand"` \| `"info"` \| `"warning"` \| `"success"` | `"default"` | The variant style of the alert |
| size      | `"sm"` \| `"md"`                                                                 | `"md"`      | The size of the alert          |
| children  | ReactNode                                                                        | -           | The content of the alert       |
| className | string                                                                           | -           | Additional CSS classes         |
