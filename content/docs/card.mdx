## Properties

| Property  | Type                                      | Default | Description             |
| --------- | ----------------------------------------- | ------- | ----------------------- |
| size      | `"sm"` \| `"md"` \| `"lg"` \| `"default"` | `"md"`  | The size of the card    |
| className | `string`                                  | -       | Additional CSS classes  |
| children  | `ReactNode`                               | -       | The content of the card |

### CardIcon

| Property  | Type             | Default | Description                    |
| --------- | ---------------- | ------- | ------------------------------ |
| size      | `"sm"` \| `"md"` | `"md"`  | The size of the icon container |
| className | `string`         | -       | Additional CSS classes         |
| children  | `ReactNode`      | -       | The icon element               |

### CardGroup

Table-style wrapper (`bg-secondary`, `rounded-2xl`) with a header band and inset content panels. Mirrors `Table` + inset `TableBody` styling.

| Component         | Description                                                                 |
| ----------------- | --------------------------------------------------------------------------- |
| `CardGroup`       | Gray outer container (same surface as `Table`)                              |
| `CardGroupHeader` | Header row on the secondary background; place `CardHeader` inside           |
| `CardGroupContent`| Inset body area with `gap-px` spacing between `CardInset` children          |
| `CardInset`       | Single inset panel (`bg-s-l0-d3`); use `CardHeader`, `CardContent`, etc.     |

#### CardGroupContent

| Property  | Type      | Default | Description                                      |
| --------- | --------- | ------- | ------------------------------------------------ |
| inset     | `boolean` | `true`  | Applies inset panel spacing and surface styles   |
| className | `string`  | -       | Additional CSS classes                         |
| children  | `ReactNode` | -     | `CardInset` elements (and optional other content) |
