## Properties

| Property  | Type                                      | Default | Description             |
| --------- | ----------------------------------------- | ------- | ----------------------- |
| size      | `"sm"` \| `"md"` \| `"lg"` \| `"default"` | `"md"`  | The size of the card    |
| className | `string`                                  | -       | Additional CSS classes  |
| children  | `ReactNode`                               | -       | The content of the card |

### CardIcon

| Property  | Type             | Default | Description                    |
| --------- | ---------------- | ------- | ------------------------------ |
| size      | `"sm"` \| `"md"` | `"md"`  | The size of the icon container |
| className | `string`         | -       | Additional CSS classes         |
| children  | `ReactNode`      | -       | The icon element               |
