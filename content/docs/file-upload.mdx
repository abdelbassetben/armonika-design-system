## Props

- `maxFiles` (number): Maximum number of files to upload. Defaults to 5.
- `maxSize` (number): Maximum size in bytes per file. Defaults to 10MB.
- `accept` (string): Allowed file types. Defaults to "\*".
- `multiple` (boolean): Whether multiple files are allowed. Defaults to true.
- `disabled` (boolean): Whether the input is disabled.
- `value` (FileUploadItem[]): Array of controlled file items for manually handling state.
- `onChange` (function): Callback triggered when files selection/status changes.
- `onUpload` (function): Async callback for handling real file upload logic and reporting progress using `onProgress`.
