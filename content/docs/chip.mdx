## Properties

| Property | Type                                 | Default      | Description                          |
| -------- | ------------------------------------ | ------------ | ------------------------------------ |
| variant  | `"secondary"` \| `"primary-flat"`  | `"secondary"`| The variant style of the chip        |
| size     | `"default"` \| `"sm"` \| `"md"` \| `"lg"` | `"default"` | The size of the chip       |
| children | `ReactNode`                          | -            | The content of the chip              |
